# GradeInsight

**Live Demo:**  
https://gradea.mainampatimadhurima.workers.dev/

## Overview

GradeInsight is a web-based academic performance calculator designed to help students accurately calculate their **CGPA**, **percentage**, and **subject-wise grades**. The application provides a simple, responsive, and intuitive interface, enabling students to evaluate their academic performance quickly without manual calculations.

Built with modern web technologies, GradeInsight streamlines grade computation and offers instant results, making it a useful tool for students across different grading systems.

---

## Features

- Calculate CGPA instantly
- Percentage calculator
- Subject-wise grade entry
- Automatic grade point calculation
- Responsive and user-friendly interface
- Real-time result updates
- Simple and intuitive design

## Installation

Clone the repository:

```bash
git clone https://github.com/your-username/GradeInsight.git
```

Navigate to the project directory:

```bash
cd GradeInsight
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## Usage

1. Enter the grades or marks for each subject.
2. View the calculated CGPA and percentage instantly.
3. Analyze overall academic performance.
4. Modify subject details to recalculate results in real time.
